# Optional Safety Car / Red Flag ownership ABI1
f1c_race_control.h supplies a versioned, process-ID plus process-creation-time scoped mapping. Authority is the atomic owner lease (NONE/SC/RF), not a heartbeat or multiword snapshot. RF request0/1/2 represents idle/reservation/takeover; request and acknowledgement revisions and SC generation provide diagnostics. SC publishes exact near-stop-controlled object identities; no game address is introduced. No owner expiry, forced takeover or broker hook duplication. Independent optional clients; matched builds required when coinstalled, legacy counterparts block rather than accept an unsafe handoff. Mapping handles intentionally live until process exit; no hot unloading/lease reclamation contract.

SC acquires before its game-tick control/maintenance paths, restores/parks on the authenticated game thread, and releases only when clean. RF first waits for SC lease release, then captures its own baseline. Cancellation releases RF only after cleanup and queued restoration complete. RF legacy worker execution is retained; this does not serialize vanilla physics. Native callbacks keep original lifecycle guards.

Verified by full SDK gate including test_race_control.py (two separately compiled DLLs sharing mapping, exclusive ownership, acknowledged release, no timeout theft). Actual mod-source harnesses and stress/geometry tests are recorded in [paired implementation](../../../development/mods/full_safety_car/trials/v0.10.33_coordination_r2/README.md). Installed private pair; native gameplay validation pending. Broker ABI/binary unchanged.
