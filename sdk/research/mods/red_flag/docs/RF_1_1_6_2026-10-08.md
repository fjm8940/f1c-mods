## Owner fix (2026-10-08)

`rf_session_end` must not write the file on the game thread. It now sets a
request flag only (`rfu_request`, like `sc_usage.h` `scu_request`); the RF worker
(`thread_main`) calls `rfu_pump()` and performs `rfu_flush("session_end")`.
`eject_teardown` keeps its worker-thread `unload` flush. `test_usage.py` now
asserts `rf_session_end` calls `rfu_request` and not `rfu_flush`, and that
`thread_main` calls `rfu_pump`. Rebuilt, tests re-run, new hash and PIN recorded.
Owner live test deferred to the combined test session (not waited on).
