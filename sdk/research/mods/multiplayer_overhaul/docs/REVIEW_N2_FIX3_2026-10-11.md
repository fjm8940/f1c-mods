## Accepted

- No mid-race native fallback once a net id is stream-seen (removes the proven
  freeze -> native -> snap warp, STALL_ANALYSIS_2026-10-11.md).

  never steps backwards (sample clock and apply time monotonic per bot).

  client holds/longest/recover-blends log.

## Bug found and fixed by Claude (n2fix3r)
- Stream data source = `bot_state_encode_hook` on native encoder 0x4C71C0, which
  runs once per native send (host log: encodes/s = 60 x bots at SendHz 60).
  Codex default NativeBotHz=10 starved the 30 Hz stream to 10 fresh poses/s
  (Codex's own comment: "30 Hz packets can repeat a 10 Hz native capture"). With
  no extrapolation, bots would step at 10 Hz.
- Fix: NativeBotHz default 30 and clamped >= BotStreamHz at config load; ini
  comment updated. Backups `*.BEFORE_20261011_n2fix3r`.
- Release build sha256 914765d59da7c066756e01e965bd473e11ecdcd60de69a9436901dcbe16e72f7
  (build.bat, no COOP_DEV_TOOLS). All 6 test scripts PASS. Staged with ini at
  %TEMP%\coop_n2fix3r (). Dev build not rebuilt.
