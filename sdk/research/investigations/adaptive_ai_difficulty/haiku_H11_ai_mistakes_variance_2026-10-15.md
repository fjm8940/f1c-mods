# H11 - AI mistakes, incidents and lap-to-lap variance (static, read-only)

Date: 2026-10-15. Static only; game process not touched. Only this file was written.
Tiers: FACT = read from C decompile or exe bytes (cited). DERIVED = inference. OPEN = not settled.
PRIOR = existing corpus claim, not re-verified here. Line refs are `functions/` file lines.
Exe bytes checked with capstone (read-only) for RandomVariationScaler (VA 0x4BEA10), the pow
wrapper (0x5881F0) and the noise-table caller (VA 0x42D2B1).

## Verdict

1. Driving is deterministic. The racing-line, steering and correction code uses no RNG (PRIOR D5 census, consistent with reads here).
2. Incident roll chance = Crash% / 100 / TotalRaceLaps per roll. No speed, grip or pace term (FACT). Pace does not raise incident probability in this path.
3. Spins and off-track events are not generated by any function read. Off-track, damage and corner events only write telemetry rows (FACT). Physical excursions come from physics, not examined (OPEN).
4. Lap-to-lap RNG noise comes mainly from the race pace gate, which only runs in traffic (section 3a).
5. Mod verdict: scale pace only through vehicle +0x44F4 (base) and/or +0x453C (live). Hold RA/QA, Crash, CompletedLaps%, strength and TotalRaceLaps constant. See section 6.

## 2. RandomVariationScaler (RVS) - FACT, one OPEN point

`functions/RandomVariationScaler_004bea10.c`, verified from exe bytes:
- 0x4BEA11: `cmp [ctrl+0x360], 7`. Equal -> reads vehicle +0x44C4 (RaceAbility). Else -> +0x44C0 (QualifyingAbility).
- `v8 = clamp(((RandLCG()%40)*0.01 - 0.01 + 1.0) - X, 0, 1)`, X = ability float (0x4BEA38-0x4BEA65).
- `v5 = min(1, (RandLCG()%50)*0.01 + 0.5)` (0x4BEAB0-0x4BEABB).
- `return 0.25*a4*(v5*v8) - 0.25 + a4`, with `a4 = ctrl+844`.
- Pow step 0x4BEA9D-0x4BEAAC: `fld v8; fld 1.334 (0x5ACDD0); call 0x5881F0; fstp v8`. Reading A (original decompile, consistent with MSVC `_CIpow` st0=exponent): v8 = v8^1.334. Reading B (PRIOR RANDOMNESS.md section 3): v8 = 1.334^v8. OPEN which is right. Either way v8 = 1 when X <= -0.01, so saturation below holds; the output range differs.
- PRIOR CONFIRMED transform: X = 0x44C4 = 0.8464 - 0.038473*RA. v8 saturates at 1 for RA >= ~22.3 and is about 0.14-0.53 at RA=0 (DERIVED).
- Missing-token defaults (`sub_424080` L50/L57/L58): RA 3.0, Crash 10.0, CL% 60.0.
- So for typical RA, the draw interval `I = a4 + 0.25*a4*v5*v8 - 0.25` saturates near 720-800 units.

## 3. Sources of lap-to-lap variation

### 3a. Pace factor 0x453C - largest RNG source in race (code FACT, cadence PRIOR)
`functions/AIAbility_00429470.c`:
- L28-L35: race path runs on the 4-s ring-buffer slot (`this[4113]`; PRIOR cadence).
- L37-L51, race only: if attack flag `this[4418]==0`, pace = max(pace-0.01, base 0x44F4); else pace = min(boost, pace+0.01), boost = base + 0.67*(1-base). Walk is at most 0.01 per slot.
- L52-L68 random gate, active only if `this[4419] != 0` (set by `Overtaking_0042af70` L13-L17 from an opponent's RA). Push (prob `(4405 - 0.5*4419)*100 >= RandLCG()%100`) sets pace to boost. Back-off sets pace to max(0.5*base, pace-0.01).
- Effect: `sub_42A780` (`AIComputePassScore_0042a780.c` L4; waypoint corner-speed limit) returns `(force*CM + CA) * wetness(4448) * pace(0x453C) * a3[33]`. Pace scales every corner-speed target. Pace range about 0.48 to 0.99 (DERIVED).
- Free air: gate needs 4419 != 0 (traffic). Otherwise the walk is deterministic, driven by attack counter 4418 (incremented in AISteering L636/L672/L1135/L1204/L1248). So the RNG gate is traffic-only; free-air +/-0.4 s is not explained by RNG in this path (DERIVED).

### 3b. Other sources
- Non-race warm-up ramp (`AIPushLap_0042a180.c` L17-L29): for SessionType != 7, pace += 0.003*min(10, lap). Deterministic.
- Tyre tier and pit plan (PRIOR D5): grip and stop timing per stop, not per corner.
- Suspension physics random site (PRIOR census, non-AI, unverified): possible shared per-lap physical noise (OPEN).

### 3c. Shared random cursor - FACT (reproducibility)
- `dword_8AAE70` (cursor) and `flt_8AAE74` (256 floats) are one stream. `sub_4B3BD0` is called with ecx=0x8AAE70 at VA 0x42D2B1 (exe bytes). It sets `this[0]=0` (cursor) and fills this[1..256] with U[0,1). So the cursor table is U[0,1), not -1..1. The globals reference (`docs/12-globals-reference.md` L259, "TrigLookup256, -1 to 1") conflicts with the code.
- Cursor (unsigned char, wraps at 256) is also advanced by AIDriverStateTransition L30/L35, AIRingBufferFieldInit L7, `AudioEventRingBufferProcessing_004feaf0.c` L64/L82-L128 and `AIDriverCountSetup_004bfd90.c` L48. Sound events therefore shift incident rolls.
- Seeding: `sub_4B3BD0` L13 `TLSFieldSetter(GetTickCount())`. Runs are not reproducible by seed (DERIVED; whether this runs every launch is OPEN).

## 4. CompletedLaps% (0x44DC)
- Parser `sub_424080` L58 (identity transform, PRIOR CONFIRMED live). Default 60.0.
- Used only in the retire roll: weight `(1 - CL/100)`, gated by ctrl+833 (AICollision L35-L37). Higher CL% = lower retire chance. Token meaning (GUESS: fraction of race before retirement allowed) not confirmed.
- Not a lap counter. Lap counter is vehicle +16444 (`lapNumber`, per `map_AICollision.md`).
- Result 2 feeds the 0..9 code draw in `EngineFailureCheck`.

## 6. Verdict for the adaptive-AI mod

Hold constant (do not write; re-check after any change):

| Field | Why |
|---|---|
| veh +0x44D0 Crash | incident chance per roll = Crash/100/TotalLaps (AICollision L30) |
| veh +0x44DC CompletedLaps% | retire weight (AICollision L37) |
| veh +0x44C4 RA, +0x44C0 QA | feed RVS v8 (draw interval) and push term 4405 |
| dword_7D01A0 strength | throttle cap via AIDifficultyScalar (0x457C); once-per-session 844 change of about 6% (640 to about 680 from s=120 to s=70; `sub_4BE760` L74-L76) |
| dword_8ACF8C TotalRaceLaps | divisor of every incident roll |
| Shared cursor / LCG | extra draws or audio events reshuffle incident rolls |

Safer lever (DERIVED): write only veh +0x44F4 (base pace) and/or +0x453C (live pace). Neither feeds RVS, Crash or CL%. Caveat: 0x453C scales the corner-speed target (`sub_42A780`), so faster pace moves cars nearer the grip limit. Resulting excursion rate is OPEN; measure live.

Expected noise:
- Race, traffic: pace gate swings pace between about 0.5*base and about 0.99 on a 4-s cadence (PRIOR). Largest RNG-driven lap spread. Size not measured.
- Free air: no RNG in racing-line path. The observed +/-0.4 s is not explained by code read here. Candidates: 4418-driven pace walk, tyre and fuel state, physics noise (OPEN).
- Incidents: count depends on scheduler passes per car (OPEN). Example: Crash 10, 20 laps = 0.5% per roll.
