Lever is a **multiplier on each car's session-start 0x44F4**, so relative RA order and car
differences stay intact. Lower 0x44F4 = slower? **Check sign in Batch 0**: paper formula gives
lower RA -> higher 0x44F4 -> faster; controller treats `k > 1` as "AI faster".

## 2. Behaviour
1. At green flag, snapshot every AI car's `base_i = 0x44F4` (session generation tagged).
2. Each time the player completes a valid lap (no pit in/out, no yellow/SC, not lap 1):
   - `P` = player lap time; `R` = reference AI lap = median of the clean laps of the
     AI cars at reference grid rank (D2) on the same lap.
   - error `e = (P - R) / R - target_gap` (target_gap from D3, default 0).
   - `k_new = clamp(k * (1 + gain * e_filtered), k_min, k_max)`; `e_filtered` = EMA over 3 laps.
   - Per-lap step limit `|Δk| <= max_step` (default 0.004 ≈ 0.3 s/lap) to avoid visible rubber-banding.
3. Write `0x44F4_i = base_i * k` for every AI car on the game thread (R2). Game ramps it.
4. Qualifying: optional (D4); uses best clean lap vs AI best laps.
5. Session end / generation change: restore `base_i` only where live value == our last write (R8), clear state (R9).
6. Persist per-track `k` in `adaptive_ai_difficulty_state.json` so next session starts near the player's level.

Precedence (R8): race control (SC/RF) > Mechanical Failures > AI Toolkit > this mod.
While SC/RF/MF owns a car's pace lever, skip that car and freeze `k`.

## 3. Settings (`adaptive_ai_difficulty.ini`, R10)
```
Enabled=1
Mode=race            ; off | race | race+qualifying
TargetRank=3         ; AI grid rank used as reference (D2)
TargetGapPct=0.0     ; + = player expected slower than reference (D3)
Gain=0.5
MaxStepPerLap=0.004
KMin=0.90
KMax=1.10
RememberPerTrack=1
```
Invalid/missing key -> default. `Enabled=0` = vanilla, no writes.

## 6. Acceptance criteria
- With mod on, player-to-reference gap converges within ±0.3 s/lap after ≤6 clean laps.
- AI order among themselves unchanged vs `k=1` (same RA ranking).
- No visible AI speed jumps: per-lap AI pace change ≤ MaxStepPerLap.
- `Enabled=0` produces byte-identical AI pace fields to vanilla.
- Restores cleanly after SC/MF interaction and session end; 3 race loads without fault.

## 8. Risks / abort
- Batch 0 shows nonlinear or unstable response -> abort live control, fall back to between-race
  slider advice via `tools/ai_difficulty_calculator.py`.
- Player benefits from slowing deliberately ("sandbagging") — mitigated by step limit + KMin; accept.
- Throttle-cap latch bug (0x457C) can cap fast AI regardless of k; note, do not fix here.

Restoration: mod off or DLL removed = vanilla; no files outside plugin folder changed.
