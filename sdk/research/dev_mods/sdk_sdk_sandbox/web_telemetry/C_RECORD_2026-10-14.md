## 3. Deviations from the spec (and why)

1. `exportDoc` on an incomplete lap: `lap_time` null (as specified) and `lap_time_src` is `"derived"` (the spec only allows game/derived). Reason: keeps the field a closed enum.
2. `exportDoc` `team` is now the team string (was the placeholder `0`). Nothing in the tree reads `doc.team` (grep). Lap docs from the server (`/trace/data`) carry a numeric team hash, which the dialog overwrites with the string in the lapset output; the hash is not kept.
3. `exportFileName(src, who, date)` got a fourth argument `ext`, because the spec's file-name pattern ends in `.<json|csv>`. Without it the helper cannot produce the full name.
4. CSV header is comma-separated without spaces (the spec lists the names in prose order; CSV needs plain commas). Names are exactly the spec list.
5. "Official time wait of 8 s" is measured in sim seconds (frame `st`), not wall clock. Reason: deterministic in tests. Effect: while the game is paused, a lap stays pending (undefined) until the sim advances; it is not set to null by wall time.
6. "Best lap per driver" uses the derived lap time (`t`) to choose; the official time is not used for the choice.
7. Only pit laps (`flags & 2`) are filtered. Break laps (`flags & 4`) are not filtered, as the spec's filter list says.
8. Driver-to-official join matches `/laps` cars by `id === slot`. This is an inference from the research (C2.4); the research marked the join as needing the C1.5 check on a live session.
9. Multi-driver selection file name uses `drivers` in place of a single name.
10. The top-bar Export button `title` text changed to describe the dialog (text only, no styling).
11. Non-spec classes added for DOM lookup only (`w-what`, `w-team`, `w-laps`, `w-pit`, `w-fmt`, `btn-export`, `btn-cancel`); no styling.
12. Dialog `Export` button is disabled while a run is in progress (behaviour, no styling).
