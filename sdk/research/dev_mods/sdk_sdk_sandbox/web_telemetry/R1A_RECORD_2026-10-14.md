## 5. Deviations (each chosen as the smallest safe option)

- **D-1 Worker thread instead of a jobs kind.** The map (1.4) and spec 5.2 put the index build on `storage_jobs.inc` as `SJ_JOB_INDEX`. That file is not in the R1-A edit list, so the build runs on a short-lived worker thread created in `storage_api.inc` (`sa_rev_worker`, `THREAD_PRIORITY_BELOW_NORMAL`, one at a time, `rv_busy`). It takes no `g_telemetry_cs` and does not touch the capture path (R-T1 holds). OPEN for Claude: move it to `storage_jobs` when that file is in scope (map D5).
- **D-2 `lap_len` not added to META.** `storage_writer.inc` is not in the R1-A list (the spec allows it only for lap_len). `GET /recordings/review` returns `"lap_len": null`. Map D6 / R1-B.
- **D-3 Other routes with a `v2_` id return 404.** `/laps`, `/trace/*`, `/telemetry` with a `v2_` id answer 404 "review data for this recording is not built yet" (after the local check). This is the R1-B adapter's job. The 1.0.1 routes never see a `v2_` id.
- **D-4 Pool size.** `sv2_index_build_rd` gets a pool of `SV2_MAX_PAYLOAD` words (4 MiB), not `SJ_POOL_WORDS` (13.6 MB). Reason: each decoded value takes at least one payload byte, so one 1 MiB block fits. If a block ever needs more, `sv2_data_decode` returns `SV2_R_BLOCK_DECODE` (no overflow).
- **D-5 Peer policy (map D4).** The new `GET /recordings/review` and the v2 refusal check `http_request_is_local` (403 for LAN peers). The 1.0.1 review routes are unchanged (still no peer check); flagged for the owner.
- **D-6 Caps.** Index holds 4096 DATA blocks (about 68 min at 1 block/s, `SW_BLOCK_TICKS` 20 at 20 Hz) and 2048 lap rows. Beyond that the index stops with `SV2_IDX_R_CAPACITY` and keeps the valid prefix (READY with reason).
- **D-7 Error cache.** An ERROR or READY slot is kept until LRU eviction; a file changed on disk is not rebuilt for the same id (INFERENCE: sessions do not change after closing).
- **D-8 `review_id` in the snapshot only** for closed or recovered sessions (spec 5.1). The published id table is capped at 256 sessions (`SA_RID_MAX`); a session beyond it has no review id (listed, not reviewable).
- **D-9 Trace sample keys / `source` values.** No trace response is produced in R1-A, so the 19-key mapping (map 3.5) is not implemented yet (R1-B).
