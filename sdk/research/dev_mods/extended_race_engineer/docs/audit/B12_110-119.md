## Method

- Shared dynamic emitters (18 functions, e.g. sub_41AC50, PitExit, RaceCommentary, TeamNameDisplayIDLookup) were read once in full. Each clip's eid was checked against each function's eid domain, with the line that gives it. A row's `checked` list has 29 entries (functions and relays). This is a deviation from "one clip at a time": the function bodies were not re-read per clip.
- The dossier's 40-function list was supplemented by a global grep over 7,143 decompiled files for literal eids in DriverDataTable / CommentaryEventQueue calls and for `= N;` assignments. The grep found sub_414010 (EnumValueTranslation), which the dossier missed. Other hits were decoder fields (BitstreamTokenReader, JPEG, sub_51B7CD, sub_58E4D2) and were judged by name only.
- Callers were traced to the per-tick root: MainGameTickUpdate (0x42C690) -> ParticleEffectUpdateDispatch (sub_4EB430, loop over all vehicles) -> CollisionDetectionSystem / VehicleContactForceAccumulation; MainGameTickUpdate every 50 ticks -> VehicleYawRotationRecoveryController (sub_4F1C40) -> sub_4F1FE0 -> sub_41B250. The enclosing gates in MainGameTickUpdate above the loop were not read.
- Tiers: clean-exe cooldown bytes and literal call sites are CONFIRMED. Reachability of the contact emitters is DERIVED. Owner-heard notes are reported as the owner's notes, with no provenance.
