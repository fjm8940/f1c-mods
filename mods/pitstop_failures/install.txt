Pit Stop Failures 1.1.4 - needs Lightloader 2.2.3 or newer.

Close the game, then install or update Pit Stop Failures in Lightloader.
Manual install: put pitstop_failures.dll and PitStopFailures.ini in
plugins/lightloader, and copy Audio into the game folder.

Custom probabilities
Edit plugins/lightloader/PitStopFailures.ini with the game closed.
incident_chance_percent accepts 0.00 through 100.00 (default 7.50).
For 100 percent in Lightloader: Show advanced settings, then set
Incident chance override percent to 100.00. The value inherit uses the main
chance control; a number from 0.00 to 100.00 overrides it.
In a text editor write: incident_chance_override_percent = 100.00
The main chance control in older managers is limited to 10; the override
remains effective even if the main value is clamped when saving that page.

The five parent types and every subtype use relative weights from 0 to 100.
Zero disables an outcome. A weight is a share within its group, not a
separate chance per stop. Keep at least one positive weight per group.
For only fuel spills: incident_chance_override_percent = 100.00; fuel_rig = 100;
set the other four parent weights to zero; fuel_spill = 100; and set
fuel_slow_flow, fuel_delayed_flow and fuel_interrupted_flow to zero.
Write each setting on its own line under the existing [PitFailures] section.
Only stops with fuel work can receive fuel faults. Eligibility is unchanged.
fuel_fire_chance_percent controls an additional fire complication on fuel
incidents (0-100 percent); unsupported fire effects are safely suppressed.

Upgrading keeps your old settings file. To get the new optional keys, open
the INI in this ZIP and copy the override/subtype/fire lines into the existing
[PitFailures] section of your installed INI, once each. Do not duplicate
keys or the section. Existing chance and parent settings can stay as they are.
Lightloader Show advanced settings exposes new keys once they are present.
The supplied INI comments explain every group and list the unchanged defaults.

Includes the three wheel-gun sounds missing from the previous package.
Reports remain controlled by Lightloader's automatic reports setting.
